# WeAI 2.0

[下载 2.0](https://github.com/eifelsir/WeAI/releases/tag/v2.0)

相对 1.0.7 的主要更新：

- 新增在线语音回复及独立服务配置，支持固定音色目录、搜索、手填音色和试听。
- ElevenLabs 默认使用 v4，补充默认中文音色；Fish 两种模型补充中文音色目录。
- 新增在线音色克隆：Fish、ElevenLabs、硅基流动及具备相应权限的官方 OpenAI 账号。上传需明确授权，OpenAI 另需授权录音；超时或结果未知时不会自动重复创建。
- 修复语音消息队列启动及原回执已结束后群聊持续忙碌的问题，完善语音优先、取消、超时和文字回退。
- 改善语音设置分页面、服务切换和保存，补充本地语音包导入与下载状态。
- 新增热更新适配扫描与缓存、互动工具和按会话主动聊天的实验入口，完善运行诊断。

本版重点为微信 8.0.78。8.0.71 / 8.0.76 / 8.0.77 的原生语音发送仍未开放，8.0.77 的原生设置入口仍待验证。在线克隆取决于服务商权限；本次未逐家进行真实创建和音质验收，本地克隆模型包尚未提供。主动聊天、工具及表情发送仍为实验能力。

保留原发布签名。按既有要求执行定向回归与安装包检查，不运行压力测试；这不代表完整测试或所有微信版本、功能均已通过实机验收。
